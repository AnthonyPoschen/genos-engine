# ADR 0039 remaining work

Accepted design: `docs/adr/0039-lighting-simplification-one-directional-world-cache.md` (Anthony, 5 Nov 2026). Sequencing after 8 Nov: land the agreed path end to end, then refine accuracy. A quality miss on the old cell picture is parked. A numerical invalid, a leak, a hang, or a missing frame wire is a functional blocker.

Columns: **functional** means the frame path does the thing. **accuracy** and **performance** are later gates. They are not reasons to keep a superseded estimator in front of a wired replacement.

## This stage

| Item | Kind | State |
|---|---|---|
| Empty fine world texel shows the trilinear neighbour read at its true normal | functional | `surface_cache.sh_texel_detail`, default off. Compose's `lighting_screen_probe_indirect` returns it. Denoiser off included. Seed, coverage, and the screen slant use that same read |
| Seed is not an own sample. Lamp change drops a stored seed, then the cells are copied again. An empty neighbour read does not keep a marked seed on screen | functional | `lighting_sc_set_seed`, confidence 0.25. The detail mark is a negative confidence. Sun word z is the quarter scratch and is not the mark. `lighting_sc_seed` refuses a negative confidence when the neighbour read is empty, on every return, including default High denoise. Unmarked seeds stay positive. Cell mean, harmonics, and read stamp are not written by the read. The read-only compose does not need the lamp clear |
| Covered texel does not also take the resample, parent, hit-patch, or probe seed | functional | An empty fine texel this setting covers does not take resample or the hit patch, even when the neighbour read accepts nothing. The probe seed still runs for that miss, so a stale, back-facing, or off-plane cell is not copied back in. Resample and the hit patch stay when the texel is not a detail candidate: detail off, a mover (not seeded), own samples, or a coarse size. The parent walk is off for every texel while texel detail is on. With texel detail on a mover shows `lighting_sh_read` at the current world position and true normal, claim false, and does not seed. A rejected read keeps the probes. Detail off still has trust 0 and shows the probes. A slant returns the cell read and does not run the texel writers |
| Covered pixel does not read screen-probe irradiance | functional | Only when that neighbour read is the displayed indirect, including a lit slant. Own samples, a parent, a resample, and a partial corner still read the probes. Place, trace, gather, and filter stay |
| Neighbour blend | functional | Eight corners, true-normal tilt. The corner weight is the trilinear weight times `dot(stored normal, query normal)`. Equal stored normals cancel that dot. Stored normals that both face the query do not, so that blend is not pure trilinear. A corner is left out when it is missing, empty, stale, back-facing (`dot <= 0`), or more than half a cell off the query plane. Left-out corners do not darken the blend. A black mean with samples does. The read does not allocate. Claim stamps only an accepted corner; seed, coverage, and slants pass claim false. Cells stay keyed by the dominant axis. The rejected four-cell lattice stays off. An axis-aligned ray hit still tilts the one owning cell. A detail candidate whose read accepts nothing does not call that hit read. SH cells on with texel detail off still does |

The six axis copies are still separate entries. The thin-wall reject uses that: the other side is a different cell, and a stored normal that faces away is left out. Collapsing those copies into one entry is not this read. A seam between dominant-axis keys is still open. A same-facing surface closer than half a cell also stays: the plane test does not reject it, so that leak is not solved here. Neither gap gets a new design in this change.

## Still in the frame, and what removes them

| Legacy path | Still runs when | Removal depends on |
|---|---|---|
| Resample and the hit patch | Not a detail candidate: texel detail off, a mover, own samples, or a coarse size | An empty fine texel with texel detail on does not run these, even when the neighbour read accepts nothing. The probe seed is the miss. SH cells on with texel detail off still runs the hit patch. A mover is not seeded. A slant returns the cell read and does not run these writers |
| Parent walk | Texel detail off | While texel detail is on the walk does not run. A mover is not seeded and does not use the walk. The walk is not put back |
| Probe seed | The neighbour read is not what the pixel shows: a miss on a covered texel, own samples, a parent, a partial corner, detail off, Low. A mover is not seeded | A covered texel with an accepted corner does not take it. A covered mover shows the world-cell read and does not store a probe seed |
| Screen-probe irradiance read in compose | The displayed indirect is not the neighbour read. That includes a miss, an empty slant, a mover whose world-cell read rejects, own samples, a parent, a resample, a partial corner, detail off, and Low | Covered pixels, including a lit slant and a mover whose read accepts a corner, skip this read. Trust 1 is not the test |
| Screen-probe place, trace, gather, and filter | Every GI frame on Medium and above that still has an uncovered pixel, an empty slant, or a mover whose world-cell read rejects. Low has no world cache | Stage 5, after the remaining probe readers are gone. Not a global probe disable. Low keeps probes until a 1060 measurement exists (ADR open question 2) |
| Mover texels | Detail off: object-frame entries, trust 0, probes. Detail on: no seed. Compose reads the world cell at the current pose and skips probes when that read is what is shown | Mover-only probe helper if cells cannot keep up (ADR decision 3). Object-frame lookup stays for detail off. Not deleted while that fallback exists |
| SVGF per-axis world read (`lighting_sc_wrc_now`) | Texel detail off, and a texel that already has samples whose field is stale | Texel detail on skips that read. The texel's own samples show instead |
| Direct per-pixel light, including the GI-on lamp-ray cost | Always. ADR D1 | D1 explains the ray count. Not this stage |
| ReSTIR and world-cell light lists | Not the bounce seed. ADR D2, where the direct path is approved | Its own stage. Temporal reuse is that reservoir's history for a matched depth and normal, not a new bounce cache |

| Probe dispatch retirement (ADR stage 5) | performance | Coverage of slanted pixels and movers, then an A/B. The compose read is already skipped for covered axis pixels. Deletion of place, trace, gather, and filter is a later change |
| GI-on lamp-ray cost (ADR D1) and reservoir memory (ADR D2) | performance | Those stages. The ~200 MB figure is a soft preference, not a hard gate. D2 is the existing ReSTIR path, not a second reservoir |
| 4070 milliseconds | performance | After an accuracy gate, on the owner's machine. Lavapipe times are not that number |

Adaptive subdivision, ray feedback into cells, and memory pools are not in the accepted ADR body. They stay out.

## Proof for this stage

`cargo test -p genos-render --test texel_detail_prod` on lavapipe. The dispatch is `lighting_screen_probe_indirect`, which compose calls. One test compiles that function with `LIGHTING_SC_WRITES` false and reads slots the writing compile planted, with no lamp clear. Rust `lighting_change_head` writes head 3.w, including bit 17, and the shader copies that word. A covered owner skips the probe read. Two planted corners blend by their trilinear weights. A missing corner stays out, and a black corner with samples darkens. A back-facing corner and a corner past half a cell off the plane stay out. The other side of a thin wall reads its own cell. A stale cell stays in memory and the pixel shows the probe. A slant shows the true-normal tilt and skips the probe read. One covered corner beside an own-sample corner does not skip. An unmarked parent with sun scratch 40 stays the parent. A marked seed whose owner is then emptied, after sun word z is cleared, shows the probe. A read-only compose with a marked green seed and an empty owner shows the probe colour `(1, 2, 3)` and leaves the stored seed. With texel detail on, a mover on a lit cell shows that cell at its current world position and true normal, skips the probe read, and does not allocate or change the cell. Moving it onto another colour, tilting the normal, and yawing it onto another axis read that pose's cell. After the mover leaves, that pose is not a mover: pose B is 8 m away and the radius is 2 m. The mover shade does not claim a world texel. The writing find then does, because the world mode is not 2. The new slot has no own samples, it is a detail candidate, and the shown value is the world cell planted at that pose. The cell key is the 25 cm size, not the 12.5 cm texel key. The cell itself is unchanged. The read-only specialization cannot claim, so the same kind of pose with no texel shows the probe. A covered mover calls `lighting_sh_read` from coverage and again from the display; the diag words count compose calls, not one lookup per pixel. Lamp-off, a missing corner, a black corner, a back face, and an off-plane corner follow the same accept rules as a static read. An empty cell, a stale cell, detail off, and Low keep the probes. A miss keeps the probes. Detail off with SH cells on, no probe, and a cell the parent and resample bilinear leave out (fractional sample count) shows that cell through the hit read. The same cell marked stale with texel detail on shows the probe. `diag[0]`, `diag[1]`, and `diag[2]` are displaying-compose skip, evaluate, and probe-irradiance counts for that one dispatch. Maintenance does not add. `cells_only` is not what this fixture counts: `covers()` ignores that toggle. The dispatch does not present a swapchain image. Zero presents is not a full frame. The read-only specialization is a second process. The planter writes the slots and exits, then the reader uploads that plant and compiles only the read-only module. On a 16 GiB lavapipe cgroup the reader alone was killed at 2026-11-08 22:05:48 UTC (pid 43125, `CONSTRAINT_MEMCG`, anon-rss 14711896 kB, total-vm 21216604 kB, shmem-rss 480000 kB). The planter had already exited. The module is `PROD_READONLY` with `LIGHTING_SC_WRITES` false, and every function longer than 1000 words is marked `DontInline`, including the 4649-word `lighting_world_irradiance_in`. The resident set sat near 9.2 GiB and then jumped. Two-row chunks, one process, and the unstripped module were already killed the same way. `spirv-opt` without inlining only shrinks that function to 4228 words. `spirv-opt -O` inlines it to 21216 words. This is not a pass of the read-only specialization. The writing specialization's dispatch is the one this machine finished. The room-blotch harness is unchanged: it does not set `sh_texel_detail`, and its 0.014 gate stays parked.
