# ADR 0039 remaining work

Accepted design: `docs/adr/0039-lighting-simplification-one-directional-world-cache.md` (Anthony, 5 Nov 2026). Sequencing after 8 Nov: land the agreed path end to end, then refine accuracy. A quality miss on the old cell picture is parked. A numerical invalid, a leak, a hang, or a missing frame wire is a functional blocker.

Columns: **functional** means the frame path does the thing. **accuracy** and **performance** are later gates. They are not reasons to keep a superseded estimator in front of a wired replacement.

## This stage

| Item | Kind | State |
|---|---|---|
| Empty fine world texel shows the trilinear neighbour read at its true normal | functional | `surface_cache.sh_texel_detail`, default off. Compose's `lighting_screen_probe_indirect` returns it. Denoiser off included. Seed, coverage, and the screen slant use that same read |
| Seed is not an own sample. Lamp change drops a stored seed, then the cells are copied again. Sun word z is the quarter scratch and is not the mark. `lighting_sc_seed` refuses a negative confidence when the neighbour read is empty, on every return, including default High denoise. The cache relight does that walk, once per enqueued texel, and compose loads the stored colour and the cells-accept bit one relight later. An empty gather clears the confidence. Unmarked seeds stay positive. Cell mean, harmonics, and read stamp are not written by the read. The read-only compose does not need the lamp clear |
| Covered texel does not also take the resample, parent, hit-patch, or probe seed | functional | An empty fine texel this setting covers does not take resample or the hit patch, even when the neighbour read accepts nothing. The probe seed still runs for that miss, so a stale, back-facing, or off-plane cell is not copied back in. Resample and the hit patch stay when the texel is not a detail candidate: detail off, a mover (not seeded), own samples, or a coarse size. The parent walk is off for every texel while texel detail is on. With texel detail on a mover shows the stored corner blend at the current world position and true normal, claim false, and does not seed. Compose loads those corner ids. The hash walk is the cache relight. A rejected read keeps the probes. Detail off still has trust 0 and shows the probes. A slant returns the cell read and does not run the texel writers |
| Covered pixel does not read screen-probe irradiance | functional | Only when that neighbour read is the displayed indirect, including a lit slant. Own samples, a parent, a resample, and a partial corner still read the probes. Place, trace, gather, and filter stay |
| Neighbour blend | functional | Eight corners, true-normal tilt. The corner weight is the trilinear weight times `dot(stored normal, query normal)`. Equal stored normals cancel that dot. Stored normals that both face the query do not, so that blend is not pure trilinear. A corner is left out when it is missing, empty, stale, back-facing (`dot <= 0`), or more than half a cell off the query plane. Left-out corners do not darken the blend. A black mean with samples does. The read does not allocate. Claim stamps only an accepted corner; seed, coverage, and slants pass claim false. Cells stay keyed by the dominant axis. The rejected four-cell lattice stays off. An axis-aligned ray hit still tilts the one owning cell. A detail candidate whose read accepts nothing does not call that hit read. SH cells on with texel detail off still does |
| Fine texel skips its own rays where the live cell read agrees | functional | `surface_cache.sh_texel_ray_cut`, default off. Requires texel detail. `lighting_compact_hold_texel_rays` runs after the 25 cm lists. Agreement is the live `lighting_sh_gather` field, not the stored seed. A 25 cm cell is not held. The read does not write the cell |

The six axis copies are still separate entries. The thin-wall reject uses that: the other side is a different cell, and a stored normal that faces away is left out. Collapsing those copies into one entry is not this read. A seam between dominant-axis keys is still open. A same-facing surface closer than half a cell also stays: the plane test does not reject it, so that leak is not solved here. Neither gap gets a new design in this change.

## Proof for this stage

`cargo test -p genos-render --test texel_detail_prod` on lavapipe. The dispatch is `lighting_screen_probe_indirect`, which compose calls. One test compiles that function with `LIGHTING_SC_WRITES` false and reads slots the writing compile planted, with no lamp clear. Rust `lighting_change_head` writes head 3.w, including bit 17, and the shader copies that word. A covered owner skips the probe read. Two planted corners blend by their trilinear weights. A missing corner stays out, and a black corner with samples darkens. A back-facing corner and a corner past half a cell off the plane stay out. The other side of a thin wall reads its own cell. A stale cell stays in memory and the pixel shows the probe. A slant shows the true-normal tilt and skips the probe read. One covered corner beside an own-sample corner does not skip. An unmarked parent with sun scratch 40 stays the parent. A marked seed whose owner is then emptied, after sun word z is cleared, shows the probe. A read-only compose with a marked green seed and an empty owner shows the probe colour `(1, 2, 3)` and leaves the stored seed. With texel detail on, a mover on a lit cell shows that cell at its current world position and true normal, skips the probe read, and does not allocate or change the cell. Moving it onto another colour, tilting the normal, and yawing it onto another axis read that pose's cell. A vacated static surface still shows its cell through the static path. Lamp-off, a missing corner, a black corner, a back face, and an off-plane corner follow the same accept rules as a static read. An empty cell, a stale cell, detail off, and Low keep the probes. A miss keeps the probes. Detail off with SH cells on, no probe, and a cell the parent and resample bilinear leave out (fractional sample count) shows that cell through the hit read. The same cell marked stale with texel detail on shows the probe. `diag[0]`, `diag[1]`, and `diag[2]` are displaying-compose skip, evaluate, and probe-irradiance counts for that one dispatch. Every compose compile, including maintenance and the sun and HDR modules, omits `lighting_sh_gather` and `lighting_sh_read`. Flags on and off are that same module. Lavapipe checks that `main` in each of them does not reach either function. The writing `texel_detail_prod` dispatch also stores one gather and checks it against the live read, then changes the cell and checks the store stays put. A slant there loads the stored corner ids and matches the live tilt. Maintenance does not add. `cells_only` is not what this fixture counts: `covers()` ignores that toggle. The dispatch does not present a swapchain image. Zero presents is not a full frame. The read-only specialization is a second device: the writing compile plants the slots, that device is dropped, and the reader uploads the plant. On a 16 GiB lavapipe cgroup that reader dispatch was killed. The resident set was sampled around 9.8 GiB and the cgroup killer then reported about 14.7 GiB anonymous, including when the shader ran two rows at a time. The same kill happened for the stripped module and for the unstripped module with DontInline on large functions. That run is not a pass of the read-only specialization. The writing specialization's dispatch is the one this machine finished. The room-blotch harness is unchanged: it does not set `sh_texel_detail`, and its 0.014 gate stays parked.

`cargo test -p genos-render --test probe_retire` on lavapipe. The command buffer plants the screen and the cells, then dispatches production `lighting_place.comp`, `lighting_trace.comp`, `lighting_gather.comp`, and `lighting_filter.comp`. Rust `lighting_change_head` writes head 3.w bit 19. A covered footprint leaves the hit slot at the sentinel, so trace returned before `trace_ray` and before the no-ray write. The live set is that probe record, not a diagnostic word and not a potential-times-rays product. This slice does not write diag[8], diag[38], or diag[39]. `gstats.pad1` is the gather bins that finished. The filter stamp is the probes that entered the filter body. A partial hole keeps the one probe that samples it and retires the other. The same covered field with the bit off keeps both probes. Detail off, Low, a stale cell, an empty cell, own samples, a missing corner, a back face, and an off-plane cell keep both. A colour split past the sparse luminance ratio still covers, so the probes retire, while `lighting_compact_hold_texel_rays` returns false. A lit slant and a mover whose world-cell read accepts retire. An empty slant and a mover whose read rejects keep the probes. Poking one uncovered pixel after a covered place brings that probe back. An empty screen retires both and does not write the hit slot. Mode 1 with a planted older stratum and a change sphere on its ray: a retired probe leaves that kept sentinel and its fill sentinel, and the stratum word stays. The same sphere retraces the kept hit and the fill when the probe is live, when the footprint has a hole, and when a hole appears after a covered place. Filter round 1 leaves a retired probe's SH mark. Round 2, the last round, clears that SH and writes the empty depth. A live probe's last round does not write that empty depth. Cell words are unchanged. The CPU `light_groups` counts do not change when the setting is on. This dispatch does not present a swapchain image. It is not a frame time. It does not rerun the stage 3 read-only compose. The base is `c342eee8`. It does not include `dfe8a29e`. A later restack keeps this slice off diag 8, 38, and 39, and does not re-prove that commit's compact lists, equal-Y hue ratio, or non-quiet lamp range.
