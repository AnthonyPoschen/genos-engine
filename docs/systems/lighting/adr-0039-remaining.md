# ADR 0039 remaining work

Accepted design: `docs/adr/0039-lighting-simplification-one-directional-world-cache.md` (Anthony, 5 Nov 2026). Sequencing after 8 Nov: land the agreed path end to end, then refine accuracy. A quality miss on the old cell picture is parked. A numerical invalid, a leak, a hang, or a missing frame wire is a functional blocker.

Columns: **functional** means the frame path does the thing. **accuracy** and **performance** are later gates. They are not reasons to keep a superseded estimator in front of a wired replacement.

## This stage

| Item | Kind | State |
|---|---|---|
| Empty fine world texel shows the trilinear neighbour read at its true normal | functional | `surface_cache.sh_texel_detail`, default off. Compose's `lighting_screen_probe_indirect` returns it. Denoiser off included. Seed, coverage, and the screen slant use that same read |
| Seed is not an own sample. Lamp change drops a stored seed, then the cells are copied again. An empty neighbour read does not keep a marked seed on screen | functional | `lighting_sc_set_seed`, confidence 0.25. The detail mark is a negative confidence. Sun word z is the quarter scratch and is not the mark. `lighting_sc_seed` refuses a negative confidence when the neighbour read is empty, on every return, including default High denoise. Unmarked seeds stay positive. Cell mean, harmonics, and read stamp are not written by the read. The read-only compose does not need the lamp clear |
| Covered texel does not also take the resample, parent, hit-patch, or probe seed | functional | An empty fine texel this setting covers does not take resample or the hit patch, even when the neighbour read accepts nothing. A stale, back-facing, or off-plane cell is not copied back in. Resample and the hit patch stay when the texel is not a detail candidate: detail off, a mover (not seeded), own samples, or a coarse size. The parent walk inside the texel is off while texel detail is on. With texel detail on a mover shows `lighting_sh_read` at the current world position and true normal, claim false, and does not seed. A rejected read mixes the parent or coarser world-cache cell by trust. Detail off uses that same fallback. A slant returns the cell read and does not run the texel writers |
| Covered pixel does not read screen-probe irradiance | functional | Only when that neighbour read is the displayed indirect, including a lit slant. Own samples, a parent, a resample, and a partial corner mix the coarser world-cache cell by trust. Place, trace, gather, and filter are removed |
| Neighbour blend | functional | Eight corners, true-normal tilt. The corner weight is the trilinear weight times `dot(stored normal, query normal)`. Equal stored normals cancel that dot. Stored normals that both face the query do not, so that blend is not pure trilinear. A corner is left out when it is missing, empty, stale, back-facing (`dot <= 0`), or more than half a cell off the query plane. Left-out corners do not darken the blend. A black mean with samples does. The read does not allocate. Claim stamps only an accepted corner; seed, coverage, and slants pass claim false. Cells stay keyed by the dominant axis. The rejected four-cell lattice stays off. An axis-aligned ray hit still tilts the one owning cell. A detail candidate whose read accepts nothing does not call that hit read. SH cells on with texel detail off still does |
| Fine texel skips its own rays where the live cell read agrees | functional | `surface_cache.sh_texel_ray_cut`, default off. Requires texel detail. `lighting_compact_hold_texel_rays` runs after the 25 cm lists. Agreement is the live `lighting_sh_gather` field, not the stored seed. A 25 cm cell is not held. The read does not write the cell |

The six axis copies are still separate entries. The thin-wall reject uses that: the other side is a different cell, and a stored normal that faces away is left out. Collapsing those copies into one entry is not this read. A seam between dominant-axis keys is still open. A same-facing surface closer than half a cell also stays: the plane test does not reject it, so that leak is not solved here. Neither gap gets a new design in this change.

## Still in the frame, and what removes them

| Legacy path | Still runs when | Removal depends on |
|---|---|---|
| Resample and the hit patch | Not a detail candidate: texel detail off, a mover, own samples, or a coarse size | An empty fine texel with texel detail on does not run these, even when the neighbour read accepts nothing. The probe seed is the miss. SH cells on with texel detail off still runs the hit patch. A mover is not seeded. A slant returns the cell read and does not run these writers |
| Parent walk | Texel detail off | While texel detail is on the walk does not run. A mover is not seeded and does not use the walk. The walk is not put back |
| Probe seed | The neighbour read is not what the pixel shows: a miss on a covered texel, own samples, a parent, a partial corner, detail off, Low. A mover is not seeded | A covered texel with an accepted corner does not take it. A covered mover shows the world-cell read and does not store a probe seed |
| Screen-probe irradiance read in compose | The displayed indirect is not the neighbour read. That includes a miss, an empty slant, a mover whose world-cell read rejects, own samples, a parent, a resample, a partial corner, detail off, and Low | Covered pixels, including a lit slant and a mover whose read accepts a corner, skip this read. Trust 1 is not the test |
| Screen-probe place, trace, gather, and filter | removed | The passes, the probe buffers they filled, and the debug knobs are gone. `probes`, `probe_rays`, `probe_tile`, `probe_refresh`, `probe_stale`, and `surface_cache.sh_probe_retire` are deprecated aliases: they parse, warn once, and do not schedule. Low and gi-1bounce read the world cache at one bounce |
| Mover texels | Detail off: object-frame entries, trust 0, probes. Detail on: no seed. Compose reads the world cell at the current pose and skips probes when that read is what is shown | Mover-only probe helper if cells cannot keep up (ADR decision 3). Object-frame lookup stays for detail off. Not deleted while that fallback exists |
| SVGF per-axis world read (`lighting_sc_wrc_now`) | Texel detail off, and a texel that already has samples whose field is stale | Texel detail on skips that read. The texel's own samples show instead |
| Direct per-pixel light, including the GI-on lamp-ray cost | Always. ADR D1 | D1 explains the ray count. Not this stage |
| ReSTIR and world-cell light lists | Not the bounce seed. ADR D2, where the direct path is approved | Its own stage. Temporal reuse is that reservoir's history for a matched depth and normal, not a new bounce cache |

## Proof for this stage

`cargo test -p genos-render --test texel_detail_prod` on lavapipe. The dispatch is `lighting_screen_probe_indirect`, which compose calls. One test compiles that function with `LIGHTING_SC_WRITES` false and reads slots the writing compile planted, with no lamp clear. Rust `lighting_change_head` writes head 3.w, including bit 17, and the shader copies that word. A covered owner skips the probe read. Two planted corners blend by their trilinear weights. A missing corner stays out, and a black corner with samples darkens. A back-facing corner and a corner past half a cell off the plane stay out. The other side of a thin wall reads its own cell. A stale cell stays in memory and the pixel shows the coarser world-cache cell when one is lit, otherwise black. A slant shows the true-normal tilt and skips the probe read. One covered corner beside an own-sample corner does not skip. An unmarked parent with sun scratch 40 stays the parent. A marked seed whose owner is then emptied, after sun word z is cleared, shows the coarser cell when one is lit, otherwise black. A read-only compose with a marked green seed and an empty owner stays black and leaves the stored seed. With texel detail on, a mover on a lit cell shows that cell at its current world position and true normal, skips the probe read, and does not allocate or change the cell. Moving it onto another colour, tilting the normal, and yawing it onto another axis read that pose's cell. A vacated static surface still shows its cell through the static path. Lamp-off, a missing corner, a black corner, a back face, and an off-plane corner follow the same accept rules as a static read. An empty cell, a stale cell, detail off, and Low show the coarser world-cache cell when one is lit, otherwise black. A miss does the same. Detail off with SH cells on, no probe, and a cell the parent and resample bilinear leave out (fractional sample count) shows that cell through the hit read. The same cell marked stale with texel detail on shows the coarser cell when one is lit, otherwise black. `diag[0]` is every displaying compose call in that dispatch. `diag[1]` and `diag[2]` stay 0. Maintenance does not add. `cells_only` is not what this fixture counts: `covers()` ignores that toggle. The dispatch does not present a swapchain image. Zero presents is not a full frame. The read-only specialization is a second device: the writing compile plants the slots, that device is dropped, and the reader uploads the plant. On a 16 GiB lavapipe cgroup that reader dispatch was killed. The resident set was sampled around 9.8 GiB and the cgroup killer then reported about 14.7 GiB anonymous, including when the shader ran two rows at a time. The same kill happened for the stripped module and for the unstripped module with DontInline on large functions. That run is not a pass of the read-only specialization. The writing specialization's dispatch is the one this machine finished. The room-blotch harness is unchanged: it does not set `sh_texel_detail`, and its 0.014 gate stays parked.

`cargo test -p genos-render --test probe_retire` is removed with the passes. The plant no longer dispatches place, gather, or filter.

`cargo test -p genos-render --test texel_ray_cut` on lavapipe. The dispatch calls `lighting_compact_hold_texel_rays`, which `lighting_compact.comp` calls after the world-cell lists. Rust `lighting_change_head` writes head 3.w, including bit 18, and the shader copies that word. A covered stable field, a field whose stored seed differs, own samples that agree while the seed differs, a valid black field, and mixed corners inside the sparse ratio are held. `diag[38]` is the held count and `diag[39]` is the rays not listed. Own samples that disagree while the seed matches the cell are not held. A later cell colour with own samples from the old colour is not held. An absent corner, an empty corner, a black corner beside a lit one, a split past the ratio, a back face, an off-plane corner, a stale cell, a stale texel, a settling lamp, a nearby move, detail off, the ray-cut bit off, Low, a 25 cm cell, and an object-local texel are not held. Cell words, the texel mean, and the seed are unchanged on a hold. The young list and the world-cell change list stay empty: the gate does not schedule them and does not write them. This dispatch does not present a swapchain image. It is not a frame time. It does not rerun `texel_detail_prod` and it does not claim that the parent's read-only specialization passed.
